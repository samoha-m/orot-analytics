# Orot Project Milestones

## Version 1.0 Stable (Current State)
* **UI & Layout:** Clean SaaS-style top navbar with OROT branding, left-aligned layout, and responsive mobile sidebar controls.
* **Multi-Language & Localization:** Full support for English (LTR), Hebrew (RTL), and Farsi (RTL) with dynamic biblical book translations for all 39 books and chart labels.
* **Language Switcher:** Crisp CDN image flag icons (🇺🇸, 🇮🇱, 🇮🇷) with active state scaling.
* **Search Engines:** 
  * Standard text search (Exact, Root, Letter, Gematria) with interactive Recharts graphs and verse preview modals.
  * Auto-discovering ELS (Equidistant Letter Sequence) engine powered by Web Workers.
* **ELS Presentation:** Filtered Context Feed displaying full natural verses, highlighting precise sequence hits, and inserting clean `...` verse gap dividers.
